# 从疑问到关联卡片

渐进阅读先给出理解问题所需的核心说明。读者需要更多细节时，点击链接展开例子、前提和边界，决定自己要读多深。

聊天用于解释阅读中的疑问；生成的回答不自动成为可靠事实。把有价值的回答整理成卡片后，应核对来源、内容和链接，再确认保存。新卡与提问卡通过普通 Markdown 内链关联。

先展开[[Acceptance/范围|本次演练的范围]]，再用卡片右上角的讨论按钮提问。本组是原创验收材料，不引用私人书籍，也不评价模型质量。
