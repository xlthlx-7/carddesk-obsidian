# 0.5.0：插件内知识整理任务

开发分支：`codex/v0.5.0-internal-card-tasks`。基线：已验收的 0.4.0 与发布记录。当前为开发构建，未发布 0.5.0 Release，不合并 main。

## 已实现范围

- Vault 内 Markdown/TXT 导入与粘贴，保存原文快照及稳定行号。
- Codex 结构建议，人工编辑确认，分批生成、停止、保存与恢复。
- 单卡编辑/排除、内部关系预览；限定目录的本地中文/英文关键词候选，选取后送模型阅读全文判关系。
- 重复卡显式复用，其他关系显式采用，旧卡不改写。
- 卡片包校验、完整文件预览、确认写入入口/新卡/清单、逐文件恢复与冲突保护。
- 复用 0.4.0 的 Codex 隔离调用、文件协议、渐进阅读、聊天和编辑。

任务独立存放在 Vault 的 Carddesk/tasks，不扩充聊天 data.json，不把材料保存在插件源码中。流程由插件编排，模型仍通过本机 Codex 调用。

## 验证与下一步

已完成自动化回归与原创材料真实宿主闭环，详见 VALIDATION_0.5.0.md；操作见 MATERIAL_TASK_GUIDE.md。每轮决策见 TEST_OPTIMIZATION_LOG.md。

下一步先做用户试用反馈、针对任务状态和文件边界的独立审查，再决定 0.5.0 发布。暂不扩充 PDF、长书、多材料、第二种 Agent。混合检索优化、独立材料/第二评审、千卡/万卡性能测试仍暂缓，不计作本轮已完成。
