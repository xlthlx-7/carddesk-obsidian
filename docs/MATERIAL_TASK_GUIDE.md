# 0.5.0 开发版：在接页里拆卡

不再需要导出说明后切到外部 Agent 手工拆卡。插件管理材料、结构、批次、关联预览和文件写入；模型仍通过已登录的本机 Codex CLI 调用，不代表模型离线运行。0.4.0 已发布版本保留，0.5.0 当前仅为开发构建。

## 开始

1. 按聊天指南配置 Codex 可执行文件。
2. 打开 Vault 内一篇 Markdown，执行“接页 Carddesk：拆成知识卡片”；文件列表右键也有该操作。
3. 或执行“知识整理任务（拆卡）”，选择 Vault 内的 `.md` / `.txt`，也可以直接粘贴文字。
4. 填写任务标题、整理重点和新卡根目录。已有卡片目录可留空；填写时，只在这个目录本地检索，不扫描全库。
5. 点击“保存材料并开始规划”。此时只保存原文快照和任务记录，不调用模型，也不创建知识卡片，不改写导入文件。

原文快照保存在 `Sources/Carddesk/<任务ID>.md`；任务记录保存在 `Carddesk/tasks/<任务ID>.json`。两者都属于用户数据，可能包含私有内容，备份 Vault 时一并保留，不要随插件源码上传。

## 先确认结构，再生成

点击“生成结构建议”，将原文和整理重点发给 Codex。插件为原文片段标记编号与行号，结构必须覆盖所有片段且不重复分配。

可以修改主题标题、核心问题、对应片段和卡数。核心问题是普通文字，不填写 Markdown 链接。确认后生成下一批；每批生成完成都会保存，下一批由你继续点击。生成后结构锁定，避免改动来源分配而让已完成卡片失去定位。需要完全不同的结构时新建任务。

卡片草稿可以展开编辑标题、正文，或取消“保留在阅读入口”。正文的关联通过下面的结构化关联列表配置，不能在正文里自行填猜测路径或引用式链接。内部关联列出目标与理由，可取消；若仍关联已排除卡片，写入校验会提示处理，不输出断链。

卡片建议 200～500 字，这只是提示，不是质量保证。来源片段和行号来自插件；模型内容仍需核对。

## 检查已有卡片关系

1. 生成全部批次后，指定已有卡片目录并点击“本地关键词检索”。检索本身不调用模型。
2. 每张新卡最多显示 3 个候选，可查看全文。关键词得分只是字面匹配信号，不是关系已经成立。
3. 勾选要交给模型检查的候选，点击“检查选中候选的关联”。每次最多 8 个候选对；将相应新卡正文及候选全文发送给 Codex。
4. 模型区分补充解释、前提、例子、重复或无明确关系。普通关系默认不采用，需要明确勾选；无依据时不加链。
5. 判定重复时，可点击“复用这张已有卡”，让入口及内部关联指向旧卡，避免新建重复卡。旧卡正文不改。

修改草稿正文、标题或搜索范围会清除之前的已有卡关系检查和复用选择，需要重新检查；内部卡片关联另行保留。候选正文变化时必须重新检索核对，不能用旧结果静默写入。

## 预览、确认并阅读

点击“保存编辑并预览写入计划”，复用卡片包校验，展示错误、提示和每个目标文件完整内容。错误会阻止写入；长度等提示可人工判断。

确认后只创建任务专属目录里的新卡、阅读入口及包清单：

- `<新卡根目录>/<任务ID>/<卡片ID>.md`
- `<新卡根目录>/<任务ID>/入口.md`
- `Carddesk/packages/<任务ID>.json`

原文件与已有卡片都不改写。新卡带稳定身份、来源快照路径、片段行号、任务追溯和待核对标记；代码块按普通代码保存，不启用模型提供的代码处理器。

完成后点“打开渐进阅读入口”，即可沿新卡及旧卡关联原地展开。阅读布局、编辑、讨论、返回、收起及阅读路径恢复沿用现有功能。

## 停止与恢复

- 处理时可以停止；关闭窗口会停止模型请求，已保存批次保留。重新执行“知识整理任务（拆卡）→ 继续已保存任务”，按任务标题选择。
- 恢复不会自动调用模型或继续写入，需要点击下一步。
- 模型返回无效 JSON、数量/片段不符合要求时，不保留半批结果；已完成批次不重做。
- 写入先冻结计划，再逐文件记录进度。中途失败或停止后，重新打开任务，确认继续剩余写入。已存在且完全一致的文件复用，不重复创建；不同内容拒绝覆盖。
- 部分写入不是跨文件事务，不会自动删除已经完成的文件。进入写入阶段后不能修改草稿，避免计划变化。若用户改过输出文件，需要手动核对冲突；不要靠重试强行覆盖。
- 原文快照变化、任务文件被外部编辑或移动时会提示，不自动覆盖。不要在运行中手改任务 JSON；先停止并备份。

## 首版范围与限额

单篇最多 30000 字符、60 个片段；单行最多 5000 字符。结构最多 10 个主题、合计 30 张卡，每批 1～10 张。单卡正文最多 4000 字符；任务最多约 4000000 个 JSON 字符。超过明确报错，不偷偷截断原文。

关键词目录最多 500 个 Markdown 文件；单候选全文最多 12000 字符，过大文件会列出跳过提示。每次候选检查最多 8 对，模型输入最多 140000 字符，响应沿用 40000 字符和 180 秒限制。任务列表首版最多保存 100 个任务，之后需自行备份整理旧任务。

首版只导入 Vault 内 Markdown/TXT 或粘贴内容，不含 PDF/OCR、整本书自动处理、多材料持续更新、向量数据库、混合检索、多 Agent 或自主改写旧卡。本地 Codex 协议兼容边界沿用聊天指南。模型调用会使用账户额度，插件不承诺固定 token 成本。
